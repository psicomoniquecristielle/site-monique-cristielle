# Site Monique Cristielle

Site institucional da psicóloga clínica Monique Cristielle (CRP 07/36651), desenvolvido como um site estático simples (HTML, CSS e JavaScript), sem frameworks ou etapa de build.

## Estrutura do projeto

Páginas: index.html (início), sobre.html, publicacoes.html e contato.html, além de 404.html para erros. Estilos e scripts: styles.css e script.js (menu mobile e interações). Pasta assets/: imagens e ícones do site. Arquivos robots.txt e sitemap.xml: configurações de SEO. Arquivo vercel.json: headers de segurança e cache usados no deploy.

## Deploy

O site é publicado automaticamente pela Vercel a cada push na branch main, e está disponível em https://www.moniquecristielle.com.
